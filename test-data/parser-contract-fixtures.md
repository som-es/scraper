# Austrian parser contract fixtures

The following public parliament API responses were copied unchanged from the
local `caching/` directory on 2026-09-30. They are fixed inputs for
`tests/austria_parser_contracts.rs`; tests never refresh them from the network.
For each path below, the original endpoint is
`https://www.parlament.gv.at/<path>?json=true` and the fixture is `<path>.json`.

- `gegenstand/XXV/ME/209`: historical ministerial proposal, ministry without person URL, subsequent government bill.
- `gegenstand/XXVIII/ME/53`: ministerial proposal with named issuer and HTML short information.
- `gegenstand/XXVII/J/14815`: written question with issuer, recipient and answer reference.
- `gegenstand/XXVIII/AB/2565`: one answer referencing five questions.
- `gegenstand/XXVII/M/384`: main question/answer, supplementary questions and written supplement.
- `gegenstand/XXII/M/171`: older page-based protocol references.
- `gegenstand/XXVIII/M/90`: newer anchor-based protocol references.

Expected identities, reference numbers, document links, dates and participants
are taken from these response fields, not generated by running the parser.
Malformed-input variants are constructed explicitly in the tests.
Calendar, government, delegate, call-to-order and enactment boundary cases use
small synthetic records. Enactment parsing resolves its legislative reference
against the existing `XXVII/A/3373` fixture.
